# illustrations-013

Resource storage for [medieval-ornaments](https://github.com/adrian729/medieval-ornaments). Main documentation and catalogs explain selection, usage, provenance and limitations.

This repository is adrian729/medieval-ornaments-assets-illustrations-013; npm delivery is `@ranx729/medieval-ornaments-assets-illustrations-013`. Versions are immutable. Consumers normally import the runtime's individual components; no resource package is installed automatically. For offline work, install the exact version reported by `getAssetSource(design)`. Public files keep their flat svg/png/webp paths; source inputs remain in Git only.

See [resource orchestration and future shards](https://github.com/adrian729/medieval-ornaments/blob/main/docs/RESOURCES.md) and LICENSE. Software and artwork have separate licensing scopes.
